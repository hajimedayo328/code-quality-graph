# Code Quality Graph

Pythonコードをグラフ理論で分析し、素人でも「どこがヤバいか」がわかる可視化ツール。
ブラウザで完結する3D可視化＋実行トレースで、コードの構造と挙動を直感的に追える。

## Live Demo

**[ブラウザで今すぐ試す →](https://hajimedayo328.github.io/code-quality-graph/)**

インストール不要。複数の Python ファイルを貼り付けて「解析する」を押すと、ブラウザ内で全処理が完結します（Pyodide 使用、サーバ送信ゼロ・オフライン完結）。

### Live Demo でできること

- **マルチファイル解析** - 複数 `.py` を同時に読み込み、モジュール間の関係も含めて解析
- **3D 呼び出しマップ** - 関数を球で、呼び出しを線で、`hub` / `bridge` / `danger` / `isolated` を色分け
- **構造異常スコア** - PageRank・中心性・複雑度の z-score 合算で「他関数と異質な構造」を 0-100 で検出
- **実行トレース** - 縦長 3D ＋値遷移ログで、関数呼び出しの順番と引数・戻り値をデバッガ風に追える
- **ランタイム機能対応** - `input` / `open` / `sys.argv` / `random.seed` / `datetime凍結` / `os.environ` / `time.sleep スキップ` / `matplotlib描画` を UI から差し替え可能
- **LLM 補助分析（任意）** - 軽量モデルを WebGPU で走らせて意味的バグの示唆と関数説明を生成（補助ツール扱い、最終判断は人間）
- **進化アニメ** - ファイル追加履歴 or git zip を読み込んで、コードがどう成長したかを再生
- **構文エラー可視化** - パースエラーを赤バナー＋ファイルカードでハイライト（無音スキップしない）

## 特徴

既存ツール（pylint, flake8）にない**グラフ理論ベースの分析**を提供:

| 分析 | pylint/flake8 | このツール |
|------|-------------|-----------|
| 変更影響分析 | なし | **あり** - 1箇所変えたら何が壊れるか |
| 呼び出しマップ | なし | **あり** - Force-Directed グラフで可視化 |
| 構造異常スコア | なし | **あり** - グラフ中心性の z-score 合算 |
| 認知的複雑度 | なし | **あり** - SonarQube 互換の読みにくさ指標 |
| 技術的負債 | なし | **あり** - 修正コストを分単位で表示 |
| セキュリティ | 別ツール | **内蔵** - eval, ハードコード秘密鍵等を検出 |
| ホットスポット | なし | **あり** - Git 変更頻度×複雑度で危険箇所検出 |
| 重複コード | 別ツール | **内蔵** - ハッシュベースで検出 |
| 実行トレース | なし | **あり** - ブラウザ内で関数呼び出しを 3D 可視化 |
| 初心者向け | 英語・難解 | **日本語・直し方付き** |

## インストール（CLI 版）

```bash
pip install code-quality-graph
```

## 使い方（CLI 版）

```bash
# カレントディレクトリを分析
code-quality-graph .

# 特定ディレクトリを分析
code-quality-graph src/

# 分析結果は HTML レポートとして出力される
# → code_quality_report.html をブラウザで開く
```

## 9 つの分析レイヤー

1. **コールグラフ** - 関数の呼び出し関係（PageRank、中心性、構造異常スコア）
2. **Import 依存** - ファイル間の依存関係（循環依存検出）
3. **変更影響** - 1箇所変えたらどこまで壊れるか
4. **重複コード** - ほぼ同じコードが複数箇所にないか（変数名込み正規化ハッシュ）
5. **認知的複雑度** - 読みにくさの数値化（SonarQube 互換）
6. **技術的負債** - 修正コストの分単位表示
7. **セキュリティ** - 危険なパターン検出（eval, ハードコード秘密鍵等）
8. **Git 履歴連携** - ホットスポット検出（変更頻度×複雑度）※CLI 版のみ
9. **総合スコア** - 100 点満点の品質スコア

## ブラウザ版のタブ構成

| タブ | 内容 |
|---|---|
| **問題点** | 直し方付きの警告一覧（high/medium 別） |
| **呼び出しマップ** | 3D Force-Directed グラフ。kind 別の色分け＋構造異常スコアでサイズ変調 |
| **Import 依存** | ファイル間の依存関係（循環依存ハイライト） |
| **変更影響** | 関数別の影響範囲バー |
| **重複コード** | ハッシュ一致した関数群 |
| **ファイル一覧** | モジュール別のスメル＋スコア |
| **全関数リスト** | スコア・認知的複雑度・技術的負債のソート可能テーブル |
| **テスト実行** | doctest を抽出して実行＋呼び出された関数を 3D ハイライト |
| **実行トレース** | 縦長 3D ＋値遷移ログでデバッガ風に追える。ランタイム設定欄あり |
| **進化を見る** | ファイル追加履歴 or git zip 読み込みで時系列再生 |
| **LLM 分析（任意）** | 意味的バグ示唆＋関数説明（WebGPU 軽量モデル、補助ツール扱い） |

## 実行トレースのランタイム機能

ブラウザ環境でも実用的なコードがトレースできるように、以下の機能を UI で差し替え可能:

| 機能 | 用途 |
|---|---|
| 📥 **stdin (input)** | `input()` に流す値を 1行=1値で事前供給 |
| 📁 **仮想ファイル (open)** | `=== filename ===` 区切りで仮想 FS を構築、書き込みは結果セクションに表示 |
| ⌨ **argv (sys.argv)** | スペース区切りで CLI 引数シミュレート |
| 🎲 **random.seed** | 乱数を固定して再現性確保 |
| 🕐 **datetime 凍結** | `datetime.now/today/utcnow` を任意の時刻に固定 |
| 🔑 **環境変数 (os.environ)** | `KEY=VALUE` で注入、終了時に元の値に復元 |
| ⏩ **time.sleep スキップ** | 長い sleep を no-op 化してトレース高速化 |
| 📊 **matplotlib** | `plt.figure()` を PNG キャプチャして UI にグリッド表示 |

検出されないライブラリ（`tkinter` / `pygame` / `requests` / `threading` / `subprocess` / `socket` 等）は事前に黄色バナーで警告し、具体的な代替策を提示します。
