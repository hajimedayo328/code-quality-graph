# Code Quality Graph

Pythonコードをグラフ理論で分析し、素人でも「どこがヤバいか」がわかるHTMLレポートを生成する。

## Live Demo

**[デモレポートを見る](https://hajimedayo328.github.io/code-quality-graph/)** (このツール自身を分析した結果)

## 特徴

既存ツール（pylint, flake8）にない**グラフ理論ベースの分析**を提供:

| 分析 | pylint/flake8 | このツール |
|------|-------------|-----------|
| 変更影響分析 | なし | **あり** - 1箇所変えたら何が壊れるか |
| 呼び出しマップ | なし | **あり** - Force-Directedグラフで可視化 |
| 認知的複雑度 | なし | **あり** - SonarQube互換の読みにくさ指標 |
| 技術的負債 | なし | **あり** - 修正コストを分単位で表示 |
| セキュリティ | 別ツール | **内蔵** - eval, ハードコード秘密鍵等を検出 |
| ホットスポット | なし | **あり** - Git変更頻度×複雑度で危険箇所検出 |
| 重複コード | 別ツール | **内蔵** - ハッシュベースで検出 |
| 初心者向け | 英語・難解 | **日本語・直し方付き** |

## インストール

```bash
pip install code-quality-graph
```

## 使い方

```bash
# カレントディレクトリを分析
code-quality-graph .

# 特定ディレクトリを分析
code-quality-graph src/

# 分析結果はHTMLレポートとして出力される
# → code_quality_report.html をブラウザで開く
```

## 9つの分析レイヤー

1. **コールグラフ** - 関数の呼び出し関係（PageRank、中心性）
2. **Import依存** - ファイル間の依存関係（循環依存検出）
3. **変更影響** - 1箇所変えたらどこまで壊れるか
4. **重複コード** - ほぼ同じコードが複数箇所にないか
5. **認知的複雑度** - 読みにくさの数値化（SonarQube互換）
6. **技術的負債** - 修正コストの分単位表示
7. **セキュリティ** - 危険なパターン検出（eval, ハードコード秘密鍵等）
8. **Git履歴連携** - ホットスポット検出（変更頻度×複雑度）
9. **総合スコア** - 100点満点の品質スコア

## スクリーンショット

HTMLレポートには以下のタブがあります:
- 問題点（直し方付き）
- 呼び出しマップ（Force-Directedグラフ）
- 変更影響（影響範囲バー）
- 重複コード
- ホットスポット（Git履歴連携）
- ファイル一覧
- 全関数リスト（スコア・認知的複雑度・技術的負債）

## 必要環境

- Python 3.10+
- numpy
- Git（ホットスポット検出に使用、なくても動作する）
